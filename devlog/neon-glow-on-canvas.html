Neon glow on a 2D canvas

28 October 2026 · Solothisgame234

The obvious way to make something glow on an HTML canvas is shadowBlur. It looks great and it's slow. Voltdart draws hundreds of glowing shapes every frame on phones, so it fakes the glow instead.

Why not shadowBlur?

shadowBlur runs a blur for every shape you draw. One glowing logo is fine. A level full of neon platforms, a ship, a trail, dozens of orbs and up to 900 particles is not, especially on mobile, where it can cut the frame rate in half. The blur also depends on screen resolution, so it gets slower the sharper the display.

Three strokes make a glow

A glow is mostly a wide, faint halo around a bright line. You can draw that directly: stroke the same path several times, wide and faint first, then narrow and bright.

function glow(color, w, core) {
  ctx.strokeStyle = color;
  ctx.globalAlpha = 0.14; ctx.lineWidth = w * 5;   ctx.stroke();  // soft halo
  ctx.globalAlpha = 0.32; ctx.lineWidth = w * 2.4; ctx.stroke();  // inner glow
  ctx.globalAlpha = 1;    ctx.lineWidth = w;       ctx.stroke();  // the tube itself
  if (core) { ctx.strokeStyle = 'rgba(255,255,255,.75)'; ctx.lineWidth = w * 0.35; ctx.stroke(); }
}

Every platform edge, hazard outline and the ship itself is drawn with this function. The optional white core is what makes it read as a neon tube rather than a colored line. Three or four strokes cost a tiny fraction of one blur.

Additive blending

Real light adds up: two overlapping glows are brighter than either one. Canvas can do that with ctx.globalCompositeOperation = 'lighter', which adds colors together instead of painting over them. Voltdart switches it on for orbs, particles, the ship's light trail and the dash afterimages. Orbs are drawn as three circles with this mode on:

  • a large, faint circle at 16% opacity for the halo,
  • a medium circle at 60% for the body,
  • a small white circle for the hot center.

Where orbs or sparks overlap, they brighten toward white, just like light. The solid shapes, such as the dark inside of the ship, are drawn in normal mode so they still cover what's behind them.

Colors with a job

The world's color shifts as the score rises: hue = 220 − 70 × cos(score / 800 + 1.13). That sweeps between cyan (150) and violet (290) and never reaches red or amber. Those two colors are reserved for hazards and never change, so at full speed your eyes can rely on them. Pretty color cycling is fine, as long as it never makes danger harder to spot.

A pixel budget for sharp screens

On a high-DPI display, a full-screen canvas can be enormous. A 2560×1440 monitor is 3.7 million pixels, and a phone at 3× density is similar. Voltdart caps the canvas at 2.4 million pixels and lowers the drawing resolution just enough to fit:

const maxPx = 2.4e6;
if (W * H * DPR * DPR > maxPx) DPR = Math.sqrt(maxPx / (W * H));

Because everything glows anyway, the slight softness at very high resolutions is invisible, and the frame rate stays steady.

Object pools: no garbage, no stutter

Creating hundreds of small objects every second (particles, orbs, floating "+80" text) makes the JavaScript garbage collector run, and a collection in the middle of a jump shows up as a stutter. Voltdart creates everything up front and reuses it:

class Pool {
  constructor(factory, size) { this.free = []; this.active = [];
    for (let i = 0; i < size; i++) this.free.push(factory()); }
  get() { const o = this.free.pop() || this.factory(); this.active.push(o); return o; }
  releaseAt(i) {               // O(1): move the last item into the gap
    const a = this.active, o = a[i]; a[i] = a[a.length - 1]; a.pop(); this.free.push(o);
  }
}

Particles get a pool of 900, orbs 200 and floating text 40. Removing an item swaps the last one into its place instead of shifting the whole array, so the update loops walk the list backwards and remove items as they go.

A city in two layers

The skyline behind the track is two layers of buildings generated once from a seeded random number generator, so they look the same every time. They scroll slower than the track (parallax), which gives depth for almost no cost. Lit windows, stars and the big synthwave sun are drawn with it. The optional CRT filter is plain CSS (scanlines and a vignette laid over the canvas), so it costs the game nothing.

See it running: play Voltdart. If it stutters on your device, the frame-rate post explains the 30 FPS option.
