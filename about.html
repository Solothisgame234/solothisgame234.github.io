About

Solothisgame234 is a small, independent game developer making free games that run in the browser. Voltdart is the first release.

The idea

Voltdart started from a simple goal: an endless runner that feels fast and fair, looks like a synthwave album cover, and loads instantly on any device. No app store, no account, no download. You open a link and you're playing within a second.

Voltdart was called Neon Drift until October 2026. So many other games use that name that this one was hard to find, so it got a name of its own. The game itself didn't change.

How it's made

  • One file. The whole game, including code, styles, graphics and sound, is a single HTML file of about 120 KB. There are no libraries, images or audio files.
  • Plain web technology. It uses HTML5 canvas for graphics, the Web Audio API for sound, and your browser's local storage to save progress.
  • Built with AI help. The game is designed and directed by Solothisgame234, and much of the code and writing was produced with Claude, an AI assistant by Anthropic. The same is disclosed on the itch.io page. Every feature is tested by playing.
  • Open about the details. The devlog explains the techniques, and the source code is on GitHub.

Where to play

  • On itch.io: stgojo123.itch.io/voltdart (as STGojo123)

How the game is funded

Voltdart is free and always will be. There is no real-money shop inside the game: crystals are earned only by playing. The developer is supported in a few optional ways:

  • ads on this website (never inside a run),
  • optional support on itch.io, where the Supporter Pack is available,
  • and players sharing the game, which helps the most.

Contact

For bug reports, ideas or questions, leave a comment on the Voltdart itch.io page or open an issue on GitHub. Both are read regularly.
